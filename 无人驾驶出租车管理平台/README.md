# 无人驾驶出租车管理平台

## 技术栈

- **后端**：Python/Flask
- **数据库**：MySQL
- **前端**：HTML, CSS, JavaScript, Bootstrap 5
- **图表**：Chart.js

## 核心算法

### 订单分配算法系统

系统采用了基于匈牙利算法的智能订单分配系统，详细的算法设计和流程图请参考：

- **[算法流程图.md](算法流程图.md)**：包含完整的订单分配算法、车辆选择算法和匈牙利算法流程图
- **[车辆选择算法.md](车辆选择算法.md)**：车辆选择算法的详细数学模型和实现步骤
- **[algorithm_flowchart.py](algorithm_flowchart.py)**：算法流程图绘制脚本，使用matplotlib生成高清算法流程图

#### 算法流程图绘制

系统提供了专用的Python脚本来生成Mermaid格式的算法流程图：

**使用方法：**
```bash
# 运行脚本生成Mermaid流程图
python algorithm_flowchart.py
```

**输出文件：**
- `algorithm_flowchart.mmd`：Mermaid源码文件，可用于GitHub、GitLab等平台
- `algorithm_flowchart.html`：HTML文件，可直接在浏览器中查看

**流程图特点：**
- **完整覆盖**：包含订单分配算法、车辆选择算法、匈牙利算法的完整流程
- **中文支持**：全中文标注，支持微软雅黑字体显示
- **颜色分类**：使用不同颜色区分开始节点、处理节点、判断节点、结束节点和算法节点
- **超大字体**：字体大小设置为34px，确保超高清晰度显示
- **数学公式**：包含关键的数学公式表示，如ETA计算、成本矩阵构建等
- **响应式设计**：自适应不同屏幕尺寸，支持缩放查看

**浏览器查看：**
直接双击`algorithm_flowchart.html`文件即可在浏览器中查看高清流程图，支持缩放和交互操作。

**平台兼容性：**
生成的`.mmd`文件可以直接在以下平台中使用：
- GitHub README文档
- GitLab项目文档  
- Notion、Obsidian等笔记软件
- 支持Mermaid的在线编辑器

#### 算法特点
- **全局最优化**：使用匈牙利算法保证车辆-订单分配的全局最优解
- **批量处理**：支持多订单批量分配，提高处理效率
- **智能降级**：当scipy不可用时自动切换到贪心算法
- **多城市并行**：支持多个城市的订单同时处理
- **任务中断**：提供任务停止机制，支持优雅中断

#### 算法步骤
1. **订单预处理**：获取订单信息并按城市分组
2. **车辆资源检查**：评估各城市可用车辆数量
3. **成本矩阵构建**：计算所有车辆到订单的预计到达时间(ETA)
4. **匈牙利算法求解**：找到总等待时间最小的全局最优分配方案
5. **分配执行**：更新订单和车辆状态完成分配

## 系统特性

### 统一的消息通知

系统采用基于Flask的Flash消息机制，提供了统一、美观的操作反馈通知：

- **统一封装**：通过`app/utils/flash_helper.py`统一管理所有消息通知
- **支持多种消息类型**：成功消息（绿色）、错误消息（红色）、警告消息（黄色）、信息消息（蓝色）
- **消息自动消失**：通知5秒后自动消失，鼠标悬停可暂停消失计时
- **全局一致性**：所有页面共享统一的消息显示风格，位于页面顶部居中
- **标准化调用接口**：
  - `flash_success()`：显示成功消息
  - `flash_error()`：显示错误消息
  - `flash_warning()`：显示警告消息
  - `flash_info()`：显示信息提示
  - `flash_add_success()`, `flash_update_success()`, `flash_delete_success()`：标准化操作反馈

## 功能模块

### 数据分析模块

数据分析模块提供了对系统关键数据的可视化分析，主要指标包括：

#### 分析指标卡片
- **平均订单金额**：最近30天内所有订单的平均金额，衡量用户单次出行的消费水平
- **充电站利用率**：当前充电站的平均使用率（当前车辆数/最大容量），反映充电基础设施的利用效率
- **每公里收益**：最近30天内每公里行程的平均收入，衡量运营效率和定价策略的合理性
- **优惠券转化率**：最近90天内已使用优惠券占总发放优惠券的百分比，评估营销策略有效性

这些核心指标提供了从运营效率、资源利用、定价策略和营销效果等多维度的业务洞察，支持管理决策。

各分析子模块还包括：
- 用户数据统计：用户增长、活跃度、留存率等数据分析
- 车辆数据统计：车辆状态分布、效率分析等
- 财务统计：收入、支出、利润分析等

### 通知管理模块

通知管理模块提供了完整的系统通知和用户通知管理功能：

#### 系统通知管理
- **通知查看**：支持分页浏览所有系统通知，包括车辆警告、订单状态、系统消息等
- **高级搜索**：支持按标题、内容、类型、优先级、状态、创建时间等多条件筛选
- **批量操作**：支持批量删除选中通知、一键全部标记为已读
- **状态管理**：实时显示通知总数、未读数量、已读数量统计
- **测试功能**：提供创建测试通知功能，便于系统调试

#### 用户通知管理
- **通知发送**：管理员可向单个用户或全体用户发送通知消息
- **用户选择**：支持从用户列表中选择特定用户作为通知接收方
- **通知历史**：查看已发送的用户通知记录，包括接收对象、状态等信息
- **通知删除**：支持删除不需要的用户通知记录

通知管理模块确保管理员能够及时获取系统重要信息，同时为用户提供有效的消息传达渠道。

## 支付系统

系统已简化为**仅使用余额支付**：

### 支付方式
- **唯一支付方式**：余额支付
- **支付流程**：所有订单自动使用用户账户余额进行支付
- **余额扣减**：订单完成时直接从用户余额中扣除相应金额
- **无余额检查**：系统允许余额不足时继续扣款（可能产生负余额）

### 收入记录
- **余额支付**：不产生收入记录（余额来源于用户充值）
- **充值收入**：用户充值时在income表中记录充值收入

### 支付配置
- 原有的城市支付方式偏好系数配置已被忽略
- `get_weighted_payment_method()` 函数固定返回"余额支付"
- 所有新订单和订单详情默认使用余额支付
